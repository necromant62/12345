# Викторина «Россия» (PowerPoint)

Файл: `Викторина_Россия.pptx`

## Как играть
1. Показываете слайд **вопроса** (текст + картинка по теме, без спойлера ответа).
2. Команда отвечает вслух.
3. Клик в любое место — слайд с **правильным ответом**.
4. Следующий клик — следующий вопрос.
5. Между раундами — слайды **блоков** (перерыв).

## Структура
- Титульный слайд
- 5 блоков × (слайд блока + 6 вопросов × (вопрос + ответ))
- Финальный слайд

Всего **67 слайдов**, **30 вопросов** (только с оранжевыми номерами из исходного списка).
