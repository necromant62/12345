# Викторина «Россия»

## Что открывать на игре

**Интерактивная версия (нужная логика с табло):**

Откройте файл:

`quiz-presentation/interactive/index.html`

Или запустите локальный сервер из папки `quiz-presentation`:

```bash
cd quiz-presentation
python3 -m http.server 8080
```

Затем в браузере: http://localhost:8080/interactive/

Нажмите **⛶ На весь экран** (или F11) и показывайте на проектор.

### Логика игры
- **3 тура**
- **5 тем** (бывшие «блоки»)
- В каждом туре по **2 вопроса из каждой темы** (всего 10 на тур)
  - I тур — вопросы 1–2 каждой темы
  - II тур — вопросы 3–4
  - III тур — вопросы 5–6
- Главный экран тура — **табло**: Тема | Вопрос 1 | Вопрос 2
- Клик по номеру → слайд вопроса с иллюстрацией
- Кнопка **«Посмотреть ответ»** → ответ крупно + вопрос мелко
- **«Вернуться к табло»** — ячейка вопроса исчезает (повторно не выбрать)
- Когда все 10 сыграны — переход к следующему туру / финалу
